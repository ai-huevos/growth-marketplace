# Phase: TEST (Compliance, SEO & Voice Validation)

## Objective
Automatically verify that the generated drafts meet the strict parameters defined in the Suit, and that no hallucinations have occurred.

## Execution Logic (Blueprint First)

1. **Draft Ingestion:** Read all files from the `drafts/` directory generated by `BUILD`.
2. **Suit Validation:**
   - Load the active suit (e.g., `auteco-brand`).
   - Run a deterministic check (using Regex or lightweight LLM evaluator) to verify that NO "Forbidden Phrasing" is present.
   - Verify that "Mandatory Inclusions" (e.g., Call-to-actions) are present.
3. **SEO / Platform Validation:**
   - E.g., Verify X (Twitter) threads are ≤ 280 chars per tweet.
   - Run keyword density checks against the SEO keywords defined in the `PLAN`.
4. **Hallucination Check:**
   - Cross-reference statistics in the drafts against `extracted_themes.json`. Flag any unverified numbers.

## Output
Generates a `test_report.md`. If the report flags critical errors, the workflow routes back to the `BUILD` phase with a correction prompt. If successful, proceeds to `REVIEW`.
