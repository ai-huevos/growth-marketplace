# dotcom-secrets

Metodologia DotCom Secrets de Russell Brunson adaptada a B2B LATAM. Plugin del [AI Huevos Growth Marketplace](../../README.md).

Stack de frameworks branded: **ESCALA** (value ladder) → **FLUJO** (funnel architecture) → **Alma** (brand soul + email system).

## Skills

### escala
Estrategia de Conversion Ascendente con Leverage Automatico. Value ladder de 4 niveles (FREE → FRONTEND → MIDDLE → BACKEND) con RADAR discovery y modelado LTV:CAC.

**Triggers**: "ESCALA", "value ladder", "escalera de valor", "LTV:CAC", "RADAR discovery", "offer suite", "pricing tiers"

### flujo
Funnel de Lanzamiento Optimizado. Metodologia unificada de funnels: 7 fases operativas + tipos de trafico + selector de tipo de funnel + benchmarks de conversion.

**Triggers**: "FLUJO", "funnel", "embudo", "sales funnel", "funnel phases", "traffic types", "squeeze page"

### alma
El alma de tu marca. Desarrollo del Attractive Character Framework (ACF) en 10 pasos + sistema de email IMAN (Soap Opera + Seinfeld sequences).

**Triggers**: "Alma", "attractive character", "brand character", "origin story", "IMAN", "Soap Opera sequence", "Seinfeld emails"

### funnel-optimization
Diagnostico de salud del funnel, A/B testing, ciclo semanal de optimizacion, y estrategia de scaling en 3 fases.

**Triggers**: "funnel optimization", "A/B test", "conversion rate", "funnel health", "scaling strategy", "90-day plan"

## Commands

### /escala
Workshop interactivo de 7 fases para disenar una ESCALA completa con RADAR discovery, diseno de 4 tiers, y calculo LTV:CAC.

```
/escala [industria, producto/servicio, o nombre de empresa]
```

### /funnel-diagnosis
Assessment diagnostico de 6 fases para evaluar salud del funnel, identificar cuellos de botella, y prescribir acciones prioritarias.

```
/funnel-diagnosis [URL del funnel, industria, o descripcion del negocio]
```

## Agents

### funnel-architect
Agente de arquitectura de funnels. Disena blueprints completos integrando FLUJO (7 fases) + ESCALA (4 tiers) + Alma (character + email strategy).

## Conexiones Cross-Plugin

- `escala` ↔ `growth-foundations/icp-analysis` — ICP informa al WHO de RADAR
- `flujo` Fase 3 ↔ `growth-foundations/quiz-funnel` — Cualificar suscriptores via quiz
- `flujo` Fase 7 ↔ `sales-blueprint/discovery-mastery` — Cambiar ambiente = discovery call
- `alma` → `copywriting-engine/email-sequences` — Alma define estrategia, copywriting-engine ejecuta copy
- `funnel-optimization` → `sales-blueprint/pipeline-management` — Marketing funnel → sales pipeline handoff

## Instalacion

```bash
# Agregar el marketplace (solo la primera vez)
/plugin marketplace add ai-huevos/growth-marketplace

# Instalar el plugin
/plugin install dotcom-secrets@growth-marketplace
```
