# FLUJO — Funnel de Lanzamiento Único y Zonificado Optimizado

Framework para diseñar, construir y optimizar funnels de venta completos, basado en la metodología de DotCom Secrets adaptada a B2B LATAM e integrada con el ecosistema de skills del marketplace.

## Filosofía: El Funnel es el Negocio

> "El problema nunca es el tráfico o la conversión. El problema siempre es el funnel."

Un funnel no es una landing page con un formulario. Es un **sistema completo** que toma a un extraño y lo transforma en un cliente de alto valor a través de una secuencia deliberada de experiencias. Cada fase filtra, cualifica y profundiza la relación.

FLUJO toma este principio y lo estructura en 7 fases ejecutables, conectadas con el resto del marketplace para crear un sistema de crecimiento integrado.

## Las 7 Fases de FLUJO

### Fase 1: Determinar Temperatura del Tráfico

Todo tráfico llega con una temperatura que define cómo debes comunicarte:

| Temperatura | Definición | Estrategia |
|-------------|-----------|------------|
| **Frío** | No te conoce, no sabe que tiene el problema | Educar, generar curiosidad, demostrar el problema |
| **Tibio** | Te conoce o conoce el problema, pero no confía aún | Demostrar credibilidad, casos de éxito, prueba social |
| **Caliente** | Te conoce, confía, listo para actuar | Oferta directa, urgencia legítima, facilitar la compra |

Para la metodología completa de tráfico, leer `frameworks/traffic-types.md`.

### Fase 2: Configurar Pre-Frame Bridge

El pre-frame bridge es el contenido que consume el prospect **antes** de llegar a tu oferta. Prepara su estado mental para que la oferta haga sentido.

**Formatos por temperatura**:
- **Frío** → Artículo educativo, video de diagnóstico, quiz
- **Tibio** → Caso de éxito, webinar, comparativa
- **Caliente** → Testimonio, demo, prueba gratuita

### Fase 3: Cualificar Suscriptores

Convertir visitantes en leads mediante un lead magnet relevante y una squeeze page optimizada.

**Elementos clave**:
- Lead magnet alineado con el dolor del ICP
- Squeeze page con un solo CTA (target: 30%+ opt-in rate)
- Thank you page con micro-compromiso siguiente

**Conexión**: Esta fase se integra directamente con **quiz-funnel** — un quiz como lead magnet cualifica Y segmenta simultáneamente.

### Fase 4: Cualificar Compradores

La primera transacción separa a los curiosos de los compradores. El frontend offer ($97-$997 en B2B) tiene como objetivo principal **identificar compradores**, no generar profit.

**Componentes**:
- Sales page con estructura de oferta irresistible
- Checkout optimizado (mínima fricción)
- Garantía que elimine el riesgo percibido

### Fase 5: Identificar Hyperactive Buyers

Los hyperactive buyers son el 10-30% que compra TODO. Monetízalos inmediatamente:

| Mecanismo | Momento | Take Rate Objetivo |
|-----------|---------|-------------------|
| **Order bump** | En el checkout | 30-40% |
| **OTO (One-Time Offer)** | Post-compra inmediato | 15-25% |
| **Downsell** | Si rechaza el OTO | 10-20% |

### Fase 6: Envejecer y Ascender la Relación

Los que no compraron en Fase 4-5 necesitan nurturing. Los que sí compraron necesitan ascender.

**Secuencias de email**:
- **Soap Opera Sequence** (primeros 5-7 días): Storytelling + conexión emocional
- **Seinfeld Sequence** (ongoing): Entretenimiento + valor + ofertas

**Conexión**: Esta fase se integra con el skill **ALMA** (Atracción y Liderazgo de Marca con Audiencias) para la estrategia de attractive character y ascensión de valor.

### Fase 7: Cambiar el Ambiente de Venta

Para ofertas high-ticket ($5,000+), el funnel digital prepara pero no cierra. Se necesita cambiar a un ambiente de mayor confianza.

**Progresión**:
1. Application funnel (filtro de cualificación)
2. Llamada de discovery / demo
3. Propuesta personalizada

**Conexión**: Esta fase se integra con **discovery-mastery** del plugin sales-blueprint para ejecutar la llamada de discovery con metodología PULSO.

Para la metodología detallada fase por fase, leer `frameworks/seven-phases.md`.

## Selección de Tipo de Funnel

No todos los negocios necesitan el mismo funnel. La selección depende del AOV (Average Order Value), ciclo de venta y modelo de negocio.

**Categorías principales**:
- **Frontend funnels** ($0-$100): Two-Step, Self-Liquidating, Continuity
- **Middle funnels** ($100-$2,000): Perfect Webinar, Invisible Webinar, Product Launch
- **Backend funnels** ($2,000+): Application Funnel, High-Ticket Phone Close

Para el árbol de decisión completo, leer `frameworks/funnel-type-selector.md`.

## Output Esperado

Al completar el diseño de FLUJO, el usuario obtiene:

1. **Mapa de funnel completo** — Las 7 fases con estrategia específica para su negocio
2. **Selección de tipo de funnel** — Tipo recomendado con justificación basada en AOV y ciclo
3. **Estrategia de tráfico** — Fuentes clasificadas por tipo (own/control/don't control) con prioridades
4. **Arquitectura de ofertas** — Frontend, OTOs, downsells, backend con precios y posicionamiento
5. **Secuencias de email** — Soap Opera + Seinfeld con estructura y triggers
6. **Benchmarks de conversión** — Métricas objetivo por fase para medir salud del funnel
7. **Plan de implementación** — Timeline semana a semana para los primeros 30 días
