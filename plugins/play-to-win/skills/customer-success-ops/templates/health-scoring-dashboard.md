## PILAR I: IMPACTO (Impact)

**Pregunta central**: Esta el cliente obteniendo impacto de nuestro producto/servicio?

### Metricas de Impacto

| Metrica | Valor Actual | Target | Score |
|---------|-------------|--------|-------|
| Impacto es 10x el precio pagado? | __________ | Si | Verde / Amarillo / Rojo |
| Se esta identificando nuevo impacto? | __________ | Si, activamente | Verde / Amarillo / Rojo |
| El impacto es importante para el cliente? | __________ | Critico para su negocio | Verde / Amarillo / Rojo |
| El servicio/producto esta siendo usado? | __________ | >70% uso activo | Verde / Amarillo / Rojo |
| Impacto racional documentado | __________ | 3+ metas medibles | Verde / Amarillo / Rojo |
| Impacto emocional identificado | __________ | Por stakeholder | Verde / Amarillo / Rojo |

### Criterios de Scoring — Pilar Impacto

| Nivel | Criterios | Score |
|-------|----------|-------|
| **Verde** | Cliente reconoce y articula el impacto. Uso activo >70%. Impacto es critico para sus operaciones. Nuevo impacto siendo identificado. | 20-25 |
| **Amarillo** | Cliente usa el producto pero no articula impacto claramente. Uso entre 40-70%. Impacto existe pero no es prioridad. No se busca nuevo impacto activamente. | 10-19 |
| **Rojo** | Cliente no reconoce impacto. Uso <40%. Servicio se percibe como "nice to have". No hay nuevas metas de impacto. | 0-9 |

**Score Pilar Impacto**: ______ / 25

### Acciones Trigger — Pilar Impacto

| Si el score es... | Entonces... |
|-------------------|-------------|
| **Verde** | Documentar impacto para caso de estudio. Explorar expansion. Compartir impacto con stakeholders ejecutivos. |
| **Amarillo** | Agendar Impact Review. Re-descubrir metas de impacto con PULSO. Compartir historias de clientes exitosos. Actualizar JIP. |
| **Rojo** | URGENTE: Agendar call de emergencia con champion. Redefinir impacto. Escalar internamente. Considerar Trigger Play de remediacion. |

---

## PILAR II: SATISFACCION (Satisfaction)

**Pregunta central**: Estan los clientes satisfechos con el nivel de soporte que reciben?

### Metricas de Satisfaccion

| Metrica | Valor Actual | Target | Score |
|---------|-------------|--------|-------|
| CSAT score (si disponible) | __________ | >4.0/5.0 | Verde / Amarillo / Rojo |
| Tiempo de respuesta a issues criticos | __________ | <4 horas | Verde / Amarillo / Rojo |
| Ha habido "momentos que importan"? | __________ | Si, documentados | Verde / Amarillo / Rojo |
| Numero de tickets de soporte abiertos | __________ | Tendencia estable/baja | Verde / Amarillo / Rojo |
| Issues criticos sin resolver | __________ | 0 | Verde / Amarillo / Rojo |
| Sentimiento general del cliente | __________ | Positivo | Verde / Amarillo / Rojo |

### Criterios de Scoring — Pilar Satisfaccion

| Nivel | Criterios | Score |
|-------|----------|-------|
| **Verde** | CSAT >4.0. Tiempo de respuesta dentro de SLA. Issues criticos resueltos rapidamente. Cliente expresa satisfaccion. Momentos que importan documentados. | 20-25 |
| **Amarillo** | CSAT 3.0-4.0. Algunos SLA no cumplidos. Issues pendientes pero en progreso. Cliente neutral. Pocos momentos que importan. | 10-19 |
| **Rojo** | CSAT <3.0. SLAs no cumplidos repetidamente. Issues criticos abiertos sin resolucion. Cliente expresando frustracion. Sin momentos positivos. | 0-9 |

**Score Pilar Satisfaccion**: ______ / 25

### Acciones Trigger — Pilar Satisfaccion

| Si el score es... | Entonces... |
|-------------------|-------------|
| **Verde** | Solicitar testimonial/referencia. Documentar best practices de soporte. Celebrar con el equipo. |
| **Amarillo** | Revisar tickets abiertos y priorizar resolucion. Agendar check-in personal con champion. Identificar pain points de soporte. |
| **Rojo** | URGENTE: Escalar a liderazgo de soporte. Agendar call con champion para recovery plan. Asignar recurso dedicado temporalmente. Plan de remediacion con timeline. |

## PILAR III: ENGAGEMENT (Compromiso)

**Pregunta central**: Que tan comprometidos estan los clientes con tu producto?

### Metricas de Engagement

| Metrica | Valor Actual | Target | Score |
|---------|-------------|--------|-------|
| KPI principal que influenciamos | __________ | Meta: __________ | Verde / Amarillo / Rojo |
| Penetracion (% equipos usando producto) | __________ | >70% | Verde / Amarillo / Rojo |
| Frecuencia de uso (daily/weekly/monthly) | __________ | Segun producto | Verde / Amarillo / Rojo |
| Tickets de soporte / tiempo de respuesta | __________ | Tendencia normal | Verde / Amarillo / Rojo |
| Asistencia a reuniones programadas | __________ | >80% | Verde / Amarillo / Rojo |
| Engagement con emails/comunicaciones | __________ | Responde <24h | Verde / Amarillo / Rojo |

### Criterios de Scoring — Pilar Engagement

| Nivel | Criterios | Score |
|-------|----------|-------|
| **Verde** | >70% penetracion. Uso frecuente y creciente. Asistencia a reuniones >80%. Responde comunicaciones <24h. KPI siendo influenciado positivamente. | 20-25 |
| **Amarillo** | 40-70% penetracion. Uso irregular. Asistencia a reuniones 50-80%. Respuestas lentas. KPI estancado. | 10-19 |
| **Rojo** | <40% penetracion. Uso declinante. Cancelaciones frecuentes de reuniones. No responde comunicaciones. KPI no siendo influenciado. Cuenta "going dark". | 0-9 |

**Score Pilar Engagement**: ______ / 25

### Acciones Trigger — Pilar Engagement

| Si el score es... | Entonces... |
|-------------------|-------------|
| **Verde** | Explorar oportunidades de expansion. Identificar nuevos use cases. Involucrar mas equipos. |
| **Amarillo** | Agendar session de re-engagement. Compartir content educativo. Proponer training refresher. Investigar barreras de adopcion. |
| **Rojo** | URGENTE: Trigger Play "Account Going Dark". Contactar a champion por canal alternativo. Escalar internamente. Preparar plan de recovery con timeline agresivo. |

## PILAR IV: ADOPCION (Adoption)

**Pregunta central**: Todos los equipos core estan utilizando el producto?

### Metricas de Adopcion

| Metrica | Valor Actual | Target | Score |
|---------|-------------|--------|-------|
| Estan los ejecutivos involucrados en EBRs? | __________ | Si, activamente | Verde / Amarillo / Rojo |
| Hay critical events proximamente? | __________ | Identificados y planeados | Verde / Amarillo / Rojo |
| Ha habido cambios en el equipo/champion? | __________ | Estable o bien transicionado | Verde / Amarillo / Rojo |
| Todos los early adopters siguen activos? | __________ | Si | Verde / Amarillo / Rojo |
| Adopcion de nuevas features/capacidades | __________ | Adoptan >50% de releases | Verde / Amarillo / Rojo |
| Plan de rollout a nuevos equipos existe? | __________ | Documentado y en progreso | Verde / Amarillo / Rojo |

### Criterios de Scoring — Pilar Adopcion

| Nivel | Criterios | Score |
|-------|----------|-------|
| **Verde** | Ejecutivos participan en EBRs. Critical events identificados y planeados. Equipo estable o bien transicionado. Early adopters activos. Nuevas features adoptadas. Rollout plan en progreso. | 20-25 |
| **Amarillo** | Ejecutivos intermitentes en EBRs. Algunos critical events no identificados. Cambios de equipo sin transicion formal. Adopcion parcial de features. Rollout plan estancado. | 10-19 |
| **Rojo** | Sin participacion ejecutiva. Critical events desconocidos o ignorados. Champion se fue sin reemplazo. Early adopters desactivados. Sin adopcion de nuevas features. Sin plan de expansion. | 0-9 |

**Score Pilar Adopcion**: ______ / 25

### Acciones Trigger — Pilar Adopcion

| Si el score es... | Entonces... |
|-------------------|-------------|
| **Verde** | Proponer expansion a nuevos equipos/departamentos. Posicionar EBR estrategico. Documentar caso de adopcion exitosa. |
| **Amarillo** | Agendar call con champion para revisar adoption roadmap. Proponer training para equipos rezagados. Identificar barreras de adopcion. Re-engager ejecutivos para proximo EBR. |
| **Rojo** | URGENTE: Trigger Play "Champion Departure" si aplica. Identificar nuevo champion. Escalar a liderazgo. Plan de recovery de adopcion. Considerar re-kickoff. |

## Validacion del Benchmark

Antes de considerar este dashboard completo, verificar:

- [ ] Los 4 pilares evaluados con metricas especificas
- [ ] Cada pilar clasificado como Verde/Amarillo/Rojo
- [ ] Score total calculado y clasificacion global asignada
- [ ] Acciones trigger definidas para cada pilar en Amarillo o Rojo
- [ ] Tendencia identificada (Mejorando/Estable/Declinando)
- [ ] Plan de accion para pilares que necesitan atencion

---

**TIP de implementacion**: Empieza con UNA metrica por pilar. No sobre-ingenierices el sistema inicial. Con el tiempo, agrega metricas segun la madurez de tu operacion de CS.
