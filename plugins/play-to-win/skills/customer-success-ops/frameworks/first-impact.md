# First Impact — Framework de Primer Impacto

Framework para definir, ejecutar y medir el First Impact (Primer Impacto) del cliente. Incluye la metrica TTFI (Time To First Impact) y el proceso completo para acelerar el logro de impacto tangible.

## Definicion

**First Impact** = el momento en que el cliente logra impacto tangible a traves del uso y adopcion de tu producto o servicio.

No es:
- Un simple login al sistema
- Completar un checklist de setup
- Una reunión de "todo esta listo"

SI es:
- El primer resultado real que contribuye a la razon por la que compraron
- Un hito medible que demuestra que la inversion esta generando valor
- El punto de inflexion donde la confianza del cliente se solidifica

## TTFI: Time To First Impact

**TTFI** = el tiempo que toma para que un cliente logre su First Impact, medido en **dias** desde el Business Kickoff.

### Por que importa el TTFI

| TTFI Corto | TTFI Largo |
|-----------|-----------|
| Clientes generalmente mas exitosos | Mayor probabilidad de churn |
| Mayor engagement con el producto | Frustracion acumulada |
| Construye momentum para adopcion completa | Pierde el momentum del "honeymoon period" |
| Valida la decision de compra internamente | Los stakeholders cuestionan la decision |
| Genera historias de exito tempranas | No hay evidencia de valor para compartir |

> **Evidencia**: La investigacion muestra que clientes con TTFI mas corto son generalmente mas exitosos, y su probabilidad de churn es mucho menor.

## Proceso para Definir First Impact

### Paso 1: Entender los tipos de impacto del cliente

Usa SPICED para descubrir multiples tipos de impacto:

```
S → Situacion actual del cliente
P → Dolor especifico que quieren resolver
I → Impactos que quieren lograr (RACIONAL + EMOCIONAL)
CE → Para cuando lo necesitan?
D → Quien esta involucrado en la decision de exito?
```

**Preguntas clave para definir First Impact**:
- "Que quieres lograr con nuestro producto?"
- "Para que fecha necesitas verlo funcionando?"
- "Cual seria el primer resultado tangible que te haria decir 'esto esta funcionando'?"
- "Si pudieras lograr UNA cosa en los primeros 30 dias, cual seria?"

### Paso 2: Priorizar entre multiples impactos

Los clientes tendran multiples metas de impacto. Para elegir el First Impact:

1. **Alcanzable**: Debe ser lograble en un periodo corto (idealmente 30-60 dias)
2. **Significativo**: Debe importarle al cliente y a sus stakeholders
3. **Medible**: Debe poder verificarse objetivamente
4. **Visible**: Debe ser algo que el cliente pueda ver y sentir
5. **Fundacional**: Debe construir la base para impactos mayores

### Paso 3: Acordar la definicion con el cliente

Documentar en el Joint Impact Plan:
- **QUE**: Definicion clara del First Impact
- **COMO**: Pasos necesarios para lograrlo
- **CUANDO**: Fecha objetivo (Critical Event)
- **QUIEN**: Responsables de ambos lados
- **MEDICION**: Como sabremos que se logro?

## Ejemplos de Definiciones de First Impact

| Industria/Producto | First Impact DEBIL | First Impact FUERTE |
|--------------------|--------------------|---------------------|
| Software de analytics | "Cuenta creada y datos cargados" | "Primer reporte generado que revela un insight accionable" |
| Plataforma de RRHH | "Empleados dados de alta en el sistema" | "Primera encuesta de engagement completada con resultados analizados" |
| Tool de ventas | "CRM configurado" | "Primer deal cerrado usando la herramienta con 30% menos de tiempo" |
| Plataforma de seguridad | "Agentes instalados" | "Primer escaneo completado que identifica 3+ vulnerabilidades reales" |
| Software de soporte | "Tickets migrados" | "Primer caso resuelto 2x mas rapido que el metodo anterior" |

## Ejecucion: De Definicion a Logro

### Secuencia Completa

```
KICKOFF                                           FIRST IMPACT ACHIEVED
  │                                                        │
  ├──> Definir First Impact (SPICED)                       │
  │    "Que quieren lograr? Para cuando?"                  │
  │                                                        │
  ├──> Alinear implementacion                              │
  │    Tareas alineadas con el impacto deseado             │
  │                                                        │
  ├──> Mantener engagement                                 │
  │    Notificaciones cortas                               │
  │    Notificar CUALQUIER retraso                         │
  │    sin importar quien lo causo                         │
  │                                                        │
  ├──> Confirmar First Impact                              │
  │    Verificar que se logro                              │
  │    Hacer que el cliente lo sepa                        │
  │                                                        │
  ├──> Actualizar JIP                                      │
  │    Alinear con nuevas metas                            │
  │                                                        │
  └──> Comunicar transicion                                │
       Email confirmando fin de onboarding                 │
       Nuevos puntos de contacto                           │
```

### Reglas de Ejecucion

1. **No perder momentum**: Moverse rapidamente de una accion a otra despues del kickoff
2. **Comunicacion constante**: Mantener al cliente informado con notificaciones cortas y frecuentes
3. **Transparencia en retrasos**: Notificar CUALQUIER retraso sin importar quien o que lo causo — la transparencia construye confianza
4. **Celebrar el logro**: Cuando se logra el First Impact, hacerlo visible — confirmar con el cliente
5. **Documentar en CRM**: Mantener al equipo bien informado via el CRM
6. **Transicion limpia**: Asegurar que la fase de Onboarding tiene un fin claro y que el cliente conoce nuevos puntos de contacto

## Medicion y Seguimiento del TTFI

### Dashboard de TTFI

| Metrica | Como medir | Benchmark |
|---------|-----------|-----------|
| **TTFI promedio** | Dias desde kickoff hasta First Impact logrado | Depende de complejidad del producto |
| **TTFI por segmento** | TTFI desglosado por tamano de cliente, industria, producto | Identificar que segmentos necesitan mas atencion |
| **% First Impact logrado** | Clientes que logran First Impact / Total clientes onboarded | Meta: >85% |
| **TTFI vs Churn** | Correlacion entre TTFI y tasa de churn a 12 meses | TTFI corto = menor churn |
| **Onboarding Churn (CR5)** | Clientes que churnan durante onboarding | Objetivo: minimizar |

### Senales de Alerta en TTFI

| Senal | Accion |
|-------|--------|
| TTFI excede el promedio por 2x | Escalation meeting interno |
| Cliente no responde a comunicaciones | Trigger Play: Account Going Dark |
| Implementacion bloqueada por dependencia interna del cliente | Involucrar champion para desbloquear |
| Definicion de First Impact fue demasiado ambiciosa | Redefinir a un hito mas alcanzable |
| Equipo del cliente cambio durante onboarding | Re-discovery call con nuevos stakeholders |

## Conexion con el Ciclo de Vida Completo

El First Impact NO es el fin — es el inicio del Motor de Impacto:

```
First Impact → Drive Impact (A1) → Recurring Impact → Expansion
     │
     └── Lograr First Impact senala el FIN de Onboarding
         y el INICIO de la fase de Adoption
```

**Despues de lograr First Impact**:
1. Actualizar el JIP con nuevas metas de impacto
2. Establecer cadencia de reuniones de adopcion
3. Activar el sistema de Health Scoring
4. Preparar Trigger Plays relevantes
5. Planificar la primera Business Review
