# Messaging Architecture

Template para construir la arquitectura de messaging completa de una empresa B2B. Cubre desde la historia del heroe hasta taglines tacticos. Es el output de la Parte 0 (Product Marketing Fundamentals) del framework de transformacion.

## Output Contract

| Campo | Requisito |
|-------|-----------|
| **Formato** | Documento Markdown con tablas fillables y checklists |
| **Secciones obligatorias** | Hero's Journey, Value Proposition Canvas, Positioning Statement, Messaging Matrix, Taglines |
| **Historias** | Minimo 3 hero's journey stories validadas |
| **Consistencia** | Core message -> Value prop -> Key messages -> Proof points deben ser coherentes |
| **Testabilidad** | Incluir plan de validacion (con quien testear, como medir) |

## Benchmark

Una messaging architecture de calidad debe:
- Producir historias que se cuentan en < 2 minutos
- Generar un positioning statement que el 100% del equipo puede recitar
- Crear 3 key messages con proof points cuantificados
- Diferenciar claramente de la competencia
- Ser testeable con 10 prospects en 2 semanas

## Seccion 3: Positioning Statement

### Formula

```
Para [target customer]
que [statement of need/opportunity],
nuestro [product/service]
es un/una [product category]
que [key benefit/value].
A diferencia de [primary competitive alternative],
nuestro producto [primary differentiation].
```

### Tu Positioning Statement

Para _____________________________ (target customer)
que _____________________________ (need/opportunity),
nuestro _____________________________ (product/service)
es un/una _____________________________ (category)
que _____________________________ (key benefit).
A diferencia de _____________________________ (competitor),
nuestro producto _____________________________ (differentiation).

### Validation Checklist
- [ ] Target customer es especifico (no "todas las empresas")
- [ ] Need/opportunity es un dolor real (no aspiracional)
- [ ] Category es reconocible (el comprador sabe donde buscar)
- [ ] Key benefit es cuantificable
- [ ] Differentiation es defendible (competencia no puede copiar facilmente)
- [ ] Equipo puede recitarlo verbatim

## Seccion 4: Messaging Architecture Matrix

| Nivel de Mensaje | Proposito | Contenido | Donde se Usa |
|-----------------|-----------|-----------|-------------|
| **Core Message** | Esencia en una oracion | _______________ | Everywhere |
| **Value Proposition** | Por que compran los clientes | _______________ | Website, pitch, propuestas |
| **Key Message 1** | Pilar de soporte #1 | _______________ | Sales decks, demos, contenido |
| **Key Message 2** | Pilar de soporte #2 | _______________ | Sales decks, demos, contenido |
| **Key Message 3** | Pilar de soporte #3 | _______________ | Sales decks, demos, contenido |
| **Proof Point 1** | Evidencia para KM1 | _______________ | Case studies, ROI, testimonios |
| **Proof Point 2** | Evidencia para KM2 | _______________ | Case studies, ROI, testimonios |
| **Proof Point 3** | Evidencia para KM3 | _______________ | Case studies, ROI, testimonios |
| **Tagline** | Hook memorable | _______________ | Ads, firmas, social |

### Coherence Check

Verificar que la piramide se sostiene:

```
                    [Core Message]
                   /      |       \
           [KM1]       [KM2]       [KM3]
            |            |            |
         [PP1]        [PP2]        [PP3]
```

- [ ] Cada Key Message soporta directamente el Core Message
- [ ] Cada Proof Point evidencia directamente su Key Message
- [ ] No hay contradicciones entre niveles
- [ ] Un prospect nuevo podria entender la piramide completa en 5 minutos

## Seccion 5: Taglines de Impacto

### Formula

```
[Verbo] + [Resultado] + [Tiempo/Multiplicador]
```

### Ejemplos de Referencia
- "Reduce costos 40% en 90 dias"
- "Duplica pipeline velocity sin agregar headcount"

### Tagline Selection Criteria
- [ ] Memorable (se queda en la cabeza)
- [ ] Especifico (no generico)
- [ ] Cuantificable (tiene numero o multiplicador)
- [ ] Diferenciado (competencia no podria usarlo)
- [ ] Actionable (implica hacer algo, no solo ser algo)

## Seccion 7: Plan de Validacion

### Test de Messaging (2 semanas)

| Paso | Actividad | Timeline | Metrica |
|------|-----------|----------|---------|
| 1 | Testear stories con 10 prospects en discovery | Semana 1-2 | Engagement rate, preguntas de follow-up |
| 2 | Medir positioning recall con equipo | Semana 1 | 100% puede recitar? |
| 3 | A/B test taglines en outreach | Semana 1-2 | Response rate por variante |
| 4 | Feedback de prospects post-call | Semana 2 | Clarity score >8/10 |
| 5 | Documentar que resuena mas | Semana 2 | Top performing messages |

### Iteracion

Despues del test de 2 semanas:
- [ ] Actualizar stories que no resonaron
- [ ] Refinar positioning basado en feedback
- [ ] Seleccionar tagline ganador
- [ ] Actualizar messaging matrix con learnings
- [ ] Rollout final al equipo completo
