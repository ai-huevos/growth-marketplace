# Sales Health Audit

Template de auditoria completa del sistema de ventas B2B. Evalua 7 dominios, identifica gaps criticos, y genera recomendaciones priorizadas con roadmap de implementacion.

## Output Contract

| Campo | Requisito |
|-------|-----------|
| **Formato** | Documento Markdown con tablas, scores, y recomendaciones |
| **Secciones obligatorias** | Executive Summary, Current State (7 dominios), Gap Analysis, Recomendaciones, Metricas, Inversion, Next Steps |
| **Score por dominio** | 0-100 con evidencia para cada score |
| **Gaps priorizados** | Minimo 3 criticos, 2 importantes, 1 nice-to-have |
| **Recomendaciones** | Con timeline (0-30, 30-90, 90+ dias) y impacto esperado |

## Benchmark

Una auditoria de calidad debe:
- Cubrir los 7 dominios sin excepcion
- Cada score debe tener evidencia observable (no opinion)
- Recomendaciones deben mapear a frameworks/fases especificas del framework de transformacion
- Gap analysis debe incluir esfuerzo estimado (bajo/medio/alto)
- El documento debe ser actionable — el lector sabe que hacer al terminar
