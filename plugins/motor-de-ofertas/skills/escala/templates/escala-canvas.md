## 4. Calculo LTV:CAC

### Revenue por cohorte de 1,000 leads

| Tier | Tasa de conversion | Clientes | Precio | Revenue |
|------|-------------------|----------|--------|---------|
| Bait | 100% (todos entran) | 1,000 | $0 | $0 |
| Frontend | ___% | ___ | $___ | $___ |
| Middle | ___% de frontend | ___ | $___ | $___ |
| Backend | ___% de middle | ___ | $___ /ano | $___ |
| **Total revenue del cohorte** | | | | **$___** |

### LTV

```
LTV = Revenue Total del Cohorte / Leads Totales
LTV = $___ / 1,000 = $___/lead
```

### CAC

| Componente | Costo mensual |
|-----------|--------------|
| Ads (LinkedIn, Meta, Google) | $___ |
| Costos de funnel (herramientas, landing pages) | $___ |
| Tiempo/equipo de ventas (si aplica) | $___ |
| **Total mensual** | **$___** |
| **Leads generados/mes** | ___ |
| **CAC** | **$___/cliente** |

### Ratio

```
LTV:CAC = $___ : $___ = ___:1
```

| Tu resultado | Diagnostico |
|-------------|-------------|
| < 1:1 | Perdiendo dinero — revisar pricing o reducir CAC |
| 1-2:1 | Breakeven — necesitas optimizar |
| 3-5:1 | Rentable — zona de escalado |
| > 5:1 | Dominando — escalar agresivamente |
