## Agenda del 1:1 (30 min)

### Si es Semana 1: Pipeline + Business Plan

```
[0:00-0:05] Check-in personal: "Como estas? Algo que deba saber?"
[0:05-0:15] Pipeline review:
  - PULSO score de deals en etapa avanzada
  - Deals nuevos vs cerrados vs perdidos
  - Forecast para el mes
[0:15-0:25] Business plan:
  - Acciones de esta semana
  - Donde necesita ayuda
  - Deals especificos para strategizar
[0:25-0:30] Compromisos + proximos pasos
```

### Si es Semana 2: Skills + Call Review

```
[0:00-0:05] Check-in personal
[0:05-0:10] Revisitar compromisos de la semana pasada
[0:10-0:20] Call review:
  - Escuchar un fragmento de call juntos (pre-seleccionada)
  - Rep se auto-evalua primero
  - Feedback con datos: 1 cosa bien + 1 mejora
[0:20-0:25] Roleplay: Re-hacer el momento critico con la mejora
[0:25-0:30] Homework para la semana
```

### Si es Semana 3: Career Growth + Sales Coaching

```
[0:00-0:05] Check-in personal
[0:05-0:15] Desarrollo profesional:
  - Donde quiere estar en 6-12 meses?
  - Que skills necesita desarrollar?
  - Que le motiva? Que le frustra?
[0:15-0:25] Sales coaching personalizado:
  - 1 skill especifica basada en ROCA
  - Practica / roleplay
[0:25-0:30] Plan de desarrollo + compromisos
```

### Si es Semana 4: Pipeline Review + Skills Refresh

```
[0:00-0:05] Check-in personal
[0:05-0:15] Pipeline close-out del mes:
  - Que cerro? Que se movio? Que se perdio?
  - Win/loss analysis rapido
  - Resultado vs target del mes
[0:15-0:25] Skills refresh:
  - Progreso en la skill que estamos trabajando
  - ROCA update: mejoro el area diagnosticada?
[0:25-0:30] Plan del proximo mes + metas
```

## Feedback Preparado

Escribir el feedback ANTES del 1:1 usando formato TOAST:

```
OBSERVACION (dato objetivo):
"En [fecha/call/situacion], note que [comportamiento especifico]."

IMPACTO (por que importa):
"Esto resulto en [consecuencia medible]."

ACCION (que hacer diferente):
"Mi sugerencia es [accion concreta y especifica]."

PREGUNTA (invitar al rep):
"Como lo ves tu? Que crees que funciono y que no?"
```
