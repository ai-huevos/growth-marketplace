# ROCA Framework — Guia Completa

ROCA (Resultados, Operación, Conocimiento, Aptitud) es el framework de diagnostico de performance de ventas de Metodología GrowthOS. Antes de coachear, diagnostica.

## Principio Fundamental

> "No entrenes a alguien en skills si el problema es de esfuerzo. No le des un playbook si el problema es que no sabe hacer la llamada."

El 80% de los problemas de performance se diagnostican mal. Un manager asume "el rep no sabe vender" cuando en realidad el rep no esta haciendo suficientes llamadas. ROCA evita este error.

## Dimension por Dimension

### R — Resultados

**Que medir**: Los outcomes finales del trabajo del rep.

| Metrica | Como medirla | Frecuencia |
|---------|-------------|------------|
| Revenue cerrado | CRM — closed won | Mensual |
| Deals cerrados | CRM — # closed won | Mensual |
| Oportunidades creadas | CRM — # new opportunities | Semanal |
| Pipeline generado | CRM — $ new pipeline | Semanal |
| Meetings de discovery | Calendario + CRM | Semanal |
| Win rate | Closed won / total opportunities | Mensual |
| Average deal size | Revenue / # deals | Mensual |
| Sales cycle length | Avg days from creation to close | Mensual |

**Si Resultados están en target**: Felicitar. Buscar si puede mejorar aun más. Modelo a seguir para el equipo.

**Si Resultados NO están en target**: No asumas por qué. Pasa al siguiente nivel: Operación.

### O — Operación (Esfuerzo / Actividad)

**Que medir**: Las actividades que el rep HACE para generar resultados.

| Metrica | Como medirla | Target tipico (SDR) | Target tipico (AE) |
|---------|-------------|---------------------|---------------------|
| Calls realizadas | Dialer / CRM logs | 50-80/dia | 15-25/dia |
| Emails enviados | Email tool / CRM | 30-50/dia | 10-20/dia |
| Social touches | LinkedIn activity | 10-20/dia | 5-10/dia |
| Meetings agendados | Calendario | 3-5/dia | 1-2/dia |
| Proposals enviadas | CRM | N/A | 3-5/semana |
| Follow-ups realizados | CRM | 20+/dia | 10+/dia |

**Si Operación está en target pero Resultados no**: El rep está haciendo la actividad pero no está convirtiendo. El problema está en HOW, no en HOW MUCH. Pasa a Conocimiento.

**Si Operación NO está en target**:

Diagnostico de esfuerzo:

| Sub-causa | Senales | Solucion |
|-----------|---------|----------|
| **Time management** | El rep esta "ocupado" pero no productivo | Bloquear tiempo, eliminar distracciones |
| **Priorizacion** | Trabaja en deals de bajo valor, ignora los buenos | Ensenar framework de priorizacion |
| **Motivacion** | Baja energia, no inicia actividad sin push | Conversacion candida: que lo motiva? |
| **Capacidad** | Demasiados deals, no da abasto | Reducir book of business, simplificar procesos |
| **Evitacion** | Evita calls/prospecting por miedo al rechazo | Roleplay progresivo + acompanar en calls reales |

### C — Conocimiento

**Que evaluar**: Lo que el rep SABE (o deberia saber).

| Area de conocimiento | Preguntas de evaluacion | Como certificar |
|---------------------|------------------------|-----------------|
| **Sales process** | Puede explicar cada etapa del pipeline? Sabe que debe pasar en cada una? | Quiz oral o escrito |
| **Product** | Puede explicar el producto en terminos de outcomes, no features? | Roleplay de elevator pitch |
| **Personas/Buyers** | Conoce los roles del buying center? Sabe que le importa a cada uno? | Describe el dia tipico de cada persona |
| **Industry** | Entiende las tendencias, regulaciones y desafios de la industria del prospect? | Discusion de caso |
| **Compelling events** | Puede identificar critical events tipicos de su mercado? | Listar top 5 CE por industria |
| **Competencia** | Conoce a los competidores, sus fortalezas y debilidades? | Battle card quiz |
| **PULSO** | Puede explicar y usar PULSO correctamente? | Scorecard de un deal real |

**Si Conocimiento está en target pero Resultados no (con Operación en target)**: El rep SABE pero no EJECUTA. Es un issue de Aptitud. Pasa a Aptitud.

**Si Conocimiento NO está en target**:

| Solucion | Cuando usarla | Formato |
|----------|--------------|---------|
| Self-study | Conocimiento basico que puede leer | Material + quiz |
| Training session | Conocimiento que requiere contexto | Sesion grupal o 1:1 |
| Shadowing | Aprender viendo a un top performer | Observar calls reales |
| Certification | Validar que aprendio | Examen formal o roleplay |

### A — Aptitud (Habilidades)

**Que evaluar**: Lo que el rep PUEDE HACER (ejecutar bajo presion).

| Skill | Como evaluarla | Score |
|-------|---------------|-------|
| **Abrir calls (AVE)** | Escuchar una call grabada. Uso ACE? Establecio agenda? | 1-5 |
| **Discovery (PULSO)** | Revisar PULSO scorecard. Todas las dimensiones cubiertas? | 1-5 |
| **Demo** | Observar demo. Conecto features con pain del prospect? | 1-5 |
| **Objection handling** | Roleplay de objeciones comunes. Respuestas efectivas? | 1-5 |
| **Email writing** | Revisar 5 emails recientes. Son personalizados y orientados a outcomes? | 1-5 |
| **Proposal writing** | Revisar ultima propuesta. Refleja el PULSO del deal? | 1-5 |
| **Trading/Close** | Escuchar call de negociacion. Tradeo o solo dio descuento? | 1-5 |
| **Follow-up** | Revisar tiempos de follow-up. <60 min post-call? | 1-5 |

**Si Aptitud es el issue**:

| Solucion | Cuando | Formato |
|----------|--------|---------|
| 1:1 Roleplay | Skill especifica necesita practica | Coach hace de prospect, rep practica |
| Peer roleplay | Multiples reps necesitan la misma skill | Reps practican entre ellos |
| Call review | Identificar patrones en calls reales | Escuchar grabacion + feedback |
| Real-time coaching | Rep listo para aplicar pero necesita apoyo | Coach escucha call en vivo |
| Shadow top performer | Rep necesita ver como se hace bien | Observar al mejor rep |

## Error Comun: El Manager que Solo Coachea Aptitud

El 70% de los managers saltan directo a "necesitas mejorar tu discovery" sin verificar:
- Esta el rep haciendo suficientes calls? (Operación)
- Sabe el rep que preguntas hacer? (Conocimiento)
- O es que no puede ejecutar bajo presion? (Aptitud)

Cada nivel requiere una intervencion diferente. Diagnostica antes de prescribir.
