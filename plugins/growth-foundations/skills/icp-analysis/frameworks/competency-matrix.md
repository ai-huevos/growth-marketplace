## Modelo de 5 Niveles

| Nivel | Nombre | Descripción | Comportamiento Observable |
|-------|--------|-------------|--------------------------|
| 0 | Básico | Conoce el concepto, no lo ejecuta | Necesita supervisión constante |
| 1 | Competente | Ejecuta con guía, sigue procesos | Sigue SOPs, pide ayuda para excepciones |
| 2 | Avanzado | Ejecuta independientemente, resuelve problemas | Adapta procesos, propone mejoras |
| 3 | Experto | Enseña a otros, crea procesos nuevos | Mentor, crea frameworks, innova |
| 4 | Líder de Industria | Referente externo, habla en conferencias | Publica, asesora, define tendencias |

## Sistema de Evaluación Basada en Evidencia

### Principio: Portfolios, No Opiniones

Cada evaluación requiere **evidencia concreta** — no la opinión del jefe ni auto-evaluación inflada.

| Tipo de evidencia | Peso | Ejemplo |
|-------------------|------|---------|
| Portfolio de trabajo | 40% | "Aquí está la campaña que lancé y sus resultados" |
| Revisión entre pares | 25% | "Mi colega validó que mi análisis competitivo fue útil para X" |
| Métricas de impacto | 25% | "Esta secuencia de emails generó X% de conversión" |
| Auto-evaluación calibrada | 10% | "Me evalúo en Nivel 2 porque puedo hacer X pero no Y" |

### Precisión target: >90% en evaluaciones

## Código de Colores para Mapa de Calor

| Color | Significado | Acción |
|-------|-------------|--------|
| 🔴 Crítico | Competencia inexistente (Nivel 0) | Contratar, delegar a agency, o automatizar con AI |
| 🟡 Desarrollo | Competencia básica (Nivel 1) | Plan de desarrollo 30-60-90 días |
| 🟢 Fortaleza | Competencia sólida (Nivel 2-3) | Mantener, hacer mentor |
| 🌟 Excepcional | Diferenciador (Nivel 4) | Amplificar externamente, construir marca |

## Plan de Implementación 30-60-90

### Mes 1: Fundación
1. Evaluar a cada persona en las 23 competencias (workshop de 2 horas)
2. Generar mapa de calor organizacional
3. Identificar los 3 gaps más críticos (🔴)
4. Decidir para cada gap: ¿contratar, delegar, o AI?

### Mes 2: Optimización
1. Iniciar planes de desarrollo para gaps 🟡
2. Probar AI para cubrir 1 gap 🔴 (ej: copywriting con /copy)
3. Implementar peer review mensual
4. Medir: ¿la evaluación genera acción o solo documentación?

### Mes 3: Escalamiento
1. Crear "Centros de Excelencia" por competencia fuerte (🟢/🌟)
2. Implementar programa de reconocimiento externo
3. Re-evaluar: ¿los gaps se cerraron?
4. Documentar: qué funcionó y qué no

## 3 Growth Loops de Competencias

### Loop 1: Amplificación Competencia-Rendimiento
```
Desarrollo de skill (Nivel 1→2)
     → Confianza + mejor output
     → Proyectos más complejos asignados
     → Aprendizaje acelerado
     → Mentoría a otros
     → Loop se amplifica
```

### Loop 2: Contagio de Excelencia
```
Talento Nivel 3-4 actúa como mentor
     → Eleva estándar del equipo
     → Atrae mejor talento externo
     → Cultura de aprendizaje
     → Más mentores
     → Loop se amplifica
```

### Loop 3: Reconocimiento Externo
```
Miembro alcanza Nivel 4
     → Habla en conferencias, publica
     → Mejora marca empleadora
     → Facilita reclutamiento
     → Más talento de calidad
     → Loop se amplifica
```
