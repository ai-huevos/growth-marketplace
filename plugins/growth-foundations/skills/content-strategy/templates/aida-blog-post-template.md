## A — ATTENTION (Headline)

Elegir una de las 3 fórmulas de headline y generar 3 variantes para testing:

### Fórmula 1: Número + Adjetivo + Keyword + Promesa
```
[Número] [Adjetivo] [Keyword Target] [para/que] [Promesa de Resultado]
```
**Ejemplo**: "7 Estrategias Probadas de Email Marketing que Generan $10k/mes en B2B"

### Fórmula 2: Cómo [Resultado Deseado] Sin [Objeción Común]
```
Cómo [lograr resultado deseado] Sin [barrera/miedo/objeción que tiene el lector]
```
**Ejemplo**: "Cómo Conseguir 50 Leads Cualificados al Mes Sin Gastar en Publicidad"

### Fórmula 3: [Período de Tiempo] para [Resultado Deseado]
```
[La forma / El método / El sistema de X tiempo] para [resultado deseado]
```
**Ejemplo**: "El Sistema de 30 Días para Duplicar tus Leads B2B con Contenido"

## I — INTEREST (Introducción)

Elegir una de las 3 fórmulas de introducción. Objetivo: enganchar al lector en los primeros 5 segundos para que se quede >5 minutos.

### Fórmula RPT: Resultado → Problema → Transformación
```
[Resultado impactante que alguien logró].
Pero antes de eso, [describir el problema que tenía — relatable para el lector].
[Cómo la transformación sucedió, conectando con lo que el post enseña].
```

### Fórmula TRP: Transformación → Resultado → Problema
```
[Describir la transformación dramática].
El resultado: [datos concretos de mejora].
¿El problema original? [Descripción del dolor que tenía antes].
En este artículo, [promesa de lo que el lector va a aprender].
```

### Fórmula CPR: Curiosidad → Problema → Resultado
```
[Pregunta o dato que genera curiosidad inmediata].
Si estás [describir el problema/situación del lector], [validar que no está solo].
[Resultado posible + preview de lo que cubre el artículo].
```

**Regla de nivel de lectura**: Escribir para nivel de 6to grado. Frases cortas. Párrafos de 1-3 líneas. Evitar jerga innecesaria.

## D — DESIRE (Cuerpo del Artículo)

### Estructura de secciones (H2/H3)

```
## [Sección 1: Contexto y diagnóstico]
- Establecer el problema con datos
- Conectar con la experiencia del lector
- Transición al "cómo resolverlo"

    ### Jab 1 — CTA de contenido upgrade (inicio del post)
    > [CTA pequeño: "Descarga el checklist de X"]

## [Sección 2: Framework / Metodología]
- Presentar el sistema paso a paso
- Incluir ejemplos concretos por cada paso
- Usar tablas, listas y elementos visuales

## [Sección 3: Implementación práctica]
- Acciones específicas que el lector puede tomar hoy
- Herramientas recomendadas
- Errores comunes a evitar

    ### Jab 2 — CTA de contenido upgrade (mitad del post)
    > [CTA de valor: "Descarga la plantilla completa de X"]

## [Sección 4: Casos reales / Prueba social]
- Case studies o ejemplos de resultados
- Datos concretos (%, $, tiempo)
- Quotes de clientes o expertos

## [Sección 5: Próximos pasos]
- Resumen de las acciones clave
- Escalar al siguiente nivel
- Conectar con oferta
```

### Reglas de formato para el cuerpo
- Párrafos de máximo 3 líneas
- Una idea por párrafo
- Usar bullet points para listas de 3+ items
- Incluir al menos 1 tabla por cada 500 palabras
- Negritas para conceptos clave (no abusar)
- Subheadings (H2/H3) cada 200-300 palabras

## A — ACTION (CTA Final)

### Jab 3 — CTA principal (final del post)

```
## [Título orientado al siguiente paso]

[1-2 frases que resuman el valor del contenido consumido].

[Transición al CTA: "Si quieres implementar esto en tu negocio..."]

**[Nombre del lead magnet / oferta]**: [Descripción en 1 frase del beneficio].

[Botón / enlace con texto de acción]:
→ [Texto del CTA: verbo en primera persona] (ej: "Quiero la plantilla gratuita")
```

### Reglas de CTA
- Usar primera persona ("Quiero", "Necesito", "Dame")
- Ser específico sobre lo que reciben
- Reducir fricción (mencionar que es gratis, sin compromiso, etc.)
- Incluir beneficio, no solo la acción

## Checklist Pre-Publicación

- [ ] Headline testeado (mínimo 3 variantes generadas)
- [ ] Introducción engancha en los primeros 5 segundos
- [ ] Nivel de lectura: 6to grado (frases cortas, sin jerga)
- [ ] 3 Jabs (CTAs de content upgrade) colocados estratégicamente
- [ ] Al menos 1 ejemplo/caso real con datos concretos
- [ ] Internal links a contenido relacionado (mínimo 2)
- [ ] Meta title y meta description optimizados para SEO
- [ ] URL slug contiene keyword principal
- [ ] Imágenes/tablas para romper bloques de texto largos
- [ ] CTA final claro con siguiente paso específico
