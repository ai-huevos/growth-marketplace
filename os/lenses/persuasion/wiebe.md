# Joanna Wiebe — 1B - Copy Execution Quality

> Conversion copy is an engineered artifact assembled from customer language through proven frameworks and validated through experimentation. The writer is not the source of the message. The customer is. Copy that sounds like a marketer wrote it fails. Copy that sounds like the customer said it converts.

*Active period*: 2011-present

## Operating beliefs
- Copy channels existing desire via customer language. It does not create desire.
- Customer research > frameworks > writing skill. Research-light = process failure.
- Copy is a hypothesis until tested. Elegance proves nothing; outcomes do.
- The magic is in editing, not drafting. First drafts should be ugly.
- In nearly every test, framework-driven copy beat creative-voice copy.
- Shorter is not better by default. Length matches what convincing requires.
- Safe copy produces flat results. Push far enough for decisive win or loss.
- Specificity and believability are directly correlated.

## Key questions (use as self-check before finalizing output)
- What copy type? (landing page, email, sales page, CTA, onboarding)
- Visitor's likely stage of awareness? (Unaware > Problem > Solution > Product > Most Aware)
- Risk level of the action? (1-10: free app=2, high-stakes purchase=10)
- Evidence of VoC research? (specific scenarios, recurring phrases, raw customer phrasing)
- Who is the ONE reader this is written for?

## Biases (disclose in output footer)
- SaaS/digital-product fluent. Assumes web-native conversion paths.
- Privileges data-grounded copy over intuition-driven creative.
- Treats committee-polished language as default failure mode.
- Weights clarity disproportionately. Harsh caps for clarity failure.
- Prefers long copy when the argument requires it.

## Limitations (suppress lens application in these contexts)
- Ultra-minimal prestige copy: Clarity/specificity criteria assume explicit value statement. Deliberate vagueness for Most Aware audiences doesn't fit the framework well.
- Story-building sections in long narrative sales letters: 'So What' applied section-by-section flags tension-building as failure when it may be functional.
- Insider/community copy: Clarity criteria assume cold visitors; in-group copy fails five-second test but converts its audience.
- Strategic positioning: Perfect execution of the wrong message would not be caught. Framework covers execution, not strategy.
- Saturated markets: Strict VoC adherence can produce undifferentiated copy that sounds like everyone else because all competitors mine the same customer language.
- Operational backlash risk: Breakthrough copy can lift conversions while triggering internal complaints that kill the campaign. Framework doesn't account for organizational politics.
- Non-conversion content: 'So What' and 'Prove It' are not designed for educational or relationship content.

## Frameworks

### Seven Sweeps Editing System
**Source**: Tutorial Tuesday series (2017-2018), Copy School, 14-Day Freelance Bootcamp

**Purpose**: Post-draft QA across seven quality dimensions. ~30 minutes total. After each sweep, go back through all previous sweeps. Clarity is checked seven times. The system is cumulative, not linear.

Seven sequential sweeps that each examine copy from a different angle, with cumulative re-checking after each pass.

#### Components
- **Clarity** — Value proposition understandable in 5 seconds. Most important sweep and multiplier for all others.
  - Key questions:
    - Five-second test: can reader state what/who/why?
    - Single-idea per unit: no conjunction stacking (and/or/but chains)?
    - No implied steps: key facts and next steps explicit?
    - No boardroom slogans: headline translates to user meaning?
    - Visuals captioned so user knows what to look at?
    - Cardinal sentences identified: do they carry core meaning?
    - Backward read: each sentence stands alone?
  - Red flags: Headline fails five-second test
- **Voice and Tone** — Voice = persistent brand personality. Tone = context-specific modulation. Must support, not compete with, clarity.
  - Key questions:
    - Line-by-line: sounds like the brand in conversation?
    - Backward pass: detect over-voice (heavy-handed, cute, performative)?
    - Tone fits context (welcome vs apology vs shutdown)?
    - Self-focus ratio: brand name and 'we/our' density low?
    - Added elements (testimonials, CTAs) match voice?
- **So What** — Every section answers 'why should I care?' from customer's POV. Line-by-line in customer voice.
  - Key questions:
    - Outcome relevance: explains what reader gets, not feature you have?
    - Personal consequence: reader maps claim to their life/work?
    - No trust gaps: trust claims earned, not assumed?
    - Hesitation pause: if evaluator pauses, users will too. Flag it.
    - Section-level: every block resolves the question?
  - Red flags: Headline fails So What
- **Prove It** — Every claim backed by evidence that is not more copy. Proof type must match claim type. Not synonymous with testimonials.
  - Key questions:
    - Claim-by-claim: what is the proof artifact?
    - Logical match: proof type matches claim? (demo for 'easy', data for 'results', screenshot for design)
    - Adjacent placement: proof near the claim it supports?
    - Proof density: primary claims adequately proved?
    - Show-and-tell: state claim, show evidence, restate what viewer saw?
  - Red flags: Primary promise lacks proof,Superiority language ('easy/results/trusted/best/#1') is unproved
- **Specificity** — Tangible, visual, reader-life-specific language. Replaces committee-polished summaries. Creates mental images without dot-connecting burden.
  - Key questions:
    - Visualization: does line create mental picture of what user does/gets/avoids?
    - Dot-connecting burden: reader translating abstractions, or copy did it?
    - Topic focus: one idea per unit, not stacked unfamiliar features?
    - Concrete anchors: numbers, before/after states, named objects?
    - No committee compression: 'streamline workflow' vs 'cut report time from 3 hours to 20 minutes'?
- **Heightened Emotion** — Reader feels understood, not just informed. Grounded in customer reality, not manufactured hype.
  - Key questions:
    - Emotional target: what should reader feel at hero, mid-page, CTA? Aligned?
    - Before/after contrast: vivid pain state and desirable after state?
    - Customer-first ratio: brand name appears max 1-2 times?
    - Testimonial function: address specific fears, not generic praise?
    - Emotion-proof integration: emotional claims backed by proof/specificity, not hype adjectives?
    - Grounded test: did a customer feel this, or did a marketer decide they should?
- **Zero Risk** — Perceived risk neutralized at moment of action. Focus on dominant risk category.
  - Key questions:
    - Risk rating (1-10) for the action being asked?
    - Primary risk category: Performance / Value / Design-Friction / Social Success / Joy?
    - Neutralizer present for that specific category?
    - CTA-adjacent: click triggers, next-step clarity, recourse info?
    - Risk-introducing language: any phrase creating NEW anxiety?
    - Focused: addressing one dominant risk, not all five?
  - Red flags: Risk 7+ with no neutralizers at CTA

#### Decision rules
- IF headline fails five-second restatement THEN clarity is LOW regardless of other sweeps.
- IF conjunction chains join multiple ideas THEN split or delete unless cleanly supporting one idea.
- IF headline/crosshead fails So What THEN require benefit-bearing rewrite or follow-on 'why it matters' line.
- IF superiority language ('easy/results/trusted') present THEN require immediate adjacent proof or weaken claim.
- IF phrase triggers 'what do they mean?' THEN replace with tangible outcome.
- IF block stacks multiple new nouns without grounding THEN collapse to one big idea + proof.
- IF feature-and-pricing dominant with no emotion THEN translate features into lived experience; use testimonials as problem-solvers not applause.
- IF high-risk CTA with no neutralizer THEN require microcommitment or specific risk reversal.

### Voice of Customer (VoC) Research Methodology
**Source**: Tutorial Tuesdays, CXL courses, CXL Live 2019, Copy School

**Purpose**: VoC is the SOURCE of copy, not supporting evidence for copy already written. 'Instead of writing your message, steal it directly from your prospects.'

Multiple research methods for extracting customer language to use as the raw material for copy.

#### Components
- **Thank-You Survey** — Post-conversion survey asking 'What was going on in your life that brought you to [try/join/buy] [product] today?' Produces moment-of-commitment triggers, desired outcome language, objections, sticky phrases. Maps to hero/headline, messaging hierarchy, objection/risk reducers.
- **Review Mining** — List keywords → Google '[keyword] reviews' → Check Amazon/G2/Capterra/TrustPilot → Collect to spreadsheet → Categorize: motivators, value prop messages, anxiety messages. Extract recurring questions, frustration language, excitement language, specific dislikes about competitors, interesting analogies, language that makes researcher pause.
- **User Testing** — Do users restate offer in similar language to headline? (Mismatch = marketer-speak.) Do users ask questions the copy already answers? (Yes = clarity/hierarchy broken.)
- **Customer Interviews** — Key question: 'What was going on in your life that brought you to [product]?' Produces rich trigger/anxiety/outcome language.
- **Sales Calls and Support Tickets** — Produces objections in prospect's own words, buying triggers, post-purchase concerns.

#### Decision rules
- IF copy uses raw/specific/unglamorous language → VoC-grounded.
- IF copy uses polished/summarized language with default marketing words → marketer-invented.
- IF vivid scenarios present that a copywriter couldn't invent → strong VoC evidence.

### Messaging Hierarchy
**Source**: Copyhackers blog (SweatBlock case study), Tutorial Tuesdays, Copy School

**Purpose**: Information ordered in the sequence the reader needs to progress toward action.

Seven sequential questions that define the correct information order on a conversion page. Top 10% matches visitor's awareness stage; remaining 90% convinces through logical sequence.

#### Components
- **Question 1** — What do you do?
- **Question 2** — Why should I care?
- **Question 3** — Am I alone in caring, or do others like me care?
- **Question 4** — Show me HOW you do what you say.
- **Question 5** — How will my life improve?
- **Question 6** — Why is it safe for me to believe you?
- **Question 7** — Now what?

#### Decision rules
- IF proof before establishing So What THEN inverted hierarchy.
- IF same claim 3+ times THEN redundancy noise.
- IF CTA appears only once requiring scroll-back THEN poor placement; repeat after persuasion blocks.

### CTA Optimization: Call to Value vs Call to Action
**Source**: Tutorial Tuesday (Button Copy, June 2020), SweatBlock case study, Book 4

**Purpose**: CTA must match reader's commitment level and funnel position.

Distinguishes between Call to Value (outcome-focused, top/mid funnel) and Call to Action (action-focused, bottom funnel near payment).

#### Components
- **Call to Value (CTV)** — Completes 'I want to ___' with desired OUTCOME. Top/mid funnel. ('Be my own boss', 'See my top option')
- **Call to Action (CTA)** — Describes literal ACTION. Bottom funnel near payment. ('Add to cart', 'Complete booking')
- **I-Want-To Test** — Fill in 'I want to ___' with button copy. Outcome = CTV. Action = CTA.

#### Decision rules
- 'Buy' is scary. Eliminate from button copy where possible.
- 'Sign up' implies work. 'Learn more' implies work. Even a tiny pinch of implied work reduces conversion.
- First-person outperforms second-person in tests ('End my scheduling hassles' > 'End your scheduling hassles').
- Click triggers near buttons: 'no credit card,' 'free shipping,' short testimonials, incentives, deadlines.
- Headline-CTA alignment: mismatch reduces clicks. 123.9% lift from aligning them.
- One primary CTA per section. 45% registration increase from simplifying to one.

### Headline Frameworks
**Source**: Book 3 (Headlines, Subheads & Value Propositions), YouTube, Conference talks

**Purpose**: The headline does 90% of the copywriting work.

Five value proposition formulas plus evaluation criteria and anti-patterns.

#### Components
- **JTBD Formula** — 'You want ___.'
- **Transformation Formula** — 'Change/Transform [what they have] into [what they want].'
- **Credibility Formula** — '[Desirable outcome] from [no-brainer makers].'
- **Differentiator Formula** — 'The [adjective] [noun] for [use case].'
- **Full-Spectrum Formula** — 'The [adj] way for [segment] to [outcome] so you can [benefit].'
- **Evil Formula (anti-pattern)** — 'Word. Word. Word.' format (e.g., 'Play. Laugh. Achieve.'). Boardroom-approved, customer-ignored.

#### Decision rules
- IF headline is a tagline/slogan → fails as value proposition.
- IF headline doesn't match awareness stage → misaligned with visitor.
- IF headline uses Evil Formula → boardroom-approved, customer-ignored.

### Long-Form Sales Page Structure
**Source**: 10x Sales Pages (Copy School), Tutorial Tuesdays

**Purpose**: Coherent structural sequence for long-form conversion pages.

Six-phase structure moving from problem through agitation, solution, authority, product tour, to close.

#### Components
- **Problem** — Meet reader at pain. Pre-headline qualifier, question loop headline, expanding lead.
- **Agitate** — Life now vs could be. Vivid low point, dream outcome, slaughter sacred cows / install new beliefs.
- **Solution** — Blue Ocean Bridge: introduce the solution that changes everything.
- **Why** — Authority through STORY, not just credentials. Testimonials solidifying beliefs. Product reveal by name.
- **Try** — Aladdin Product Tour: each element as mini sales page. Bonuses. Reinforcing proofs.
- **Buy** — Golden Guarantee, Upgraded FAQ (objection-flipping), 'Perfect For You If' qualifier, final appeal, MVC challenge.

#### Decision rules
- IF product introduced before pain established → premature reveal.
- IF authority via credentials only (no story) → weaker persuasion.
- IF offer not stacked with value before price → price feels high.
- IF FAQs don't flip real objections → missed opportunity.

### Stages of Awareness (Schwartz, adapted by Wiebe)
**Source**: Breakthrough Advertising adapted for digital

**Purpose**: Copy must match awareness stage of arriving visitor.

Five awareness stages that determine what the opening copy must accomplish.

#### Components
- **Most Aware** — Needs: offer/deal.
- **Product Aware** — Needs: differentiation, proof it's the right choice.
- **Solution Aware** — Needs: why yours is different and better.
- **Problem Aware** — Needs: education that solutions exist.
- **Unaware** — Needs: problem identification.

#### Decision rules
- Opening MUST match arriving visitor's stage.
- Product features for Problem Aware = lost.
- Problem education for Most Aware = wasted.

### Supporting Frameworks
**Source**: Various Copyhackers sources

**Purpose**: Supplementary principles applied across all copy work.

Three supporting frameworks: Rule of One, Three Essential Techniques, and Breakthrough or Bust.

#### Components
- **Rule of One** — One reader, one big idea, one promise, one offer. Violation = page tries to be everything to everyone.
- **Front-Loading** — Important info first in sentences and sections.
- **Even-If Technique** — Objection-stomper: [Benefit] even if [biggest objection].
- **Connecting Dots** — Never burden reader with figuring out implications. State them.
- **Breakthrough or Bust** — Push copy far enough for decisive win or loss. Safe copy = flat results. Checklist: Boldly breaks best practices for medium? Runs counter to Control? Still on-brand? Makes you scared to present it? WHY for every practice challenged?

#### Decision rules
- IF page serves multiple readers/ideas/offers → Rule of One violated.
- IF important info buried late → front-loading needed.
- IF reader must figure out implications → dots not connected.
- IF copy is safe and unlikely to produce strong reaction → breakthrough or bust not applied.
