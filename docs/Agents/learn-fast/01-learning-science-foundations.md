# Accelerated Learning Science: Evidence-Backed Principles

## Overview
The ten most evidence-backed cognitive science principles that accelerate learning. Every roadmap generated by this system must incorporate these principles by default. Each principle includes mechanism, effect size, implementation rules, and failure conditions.

## How does spaced repetition work and when should it be used?
Memory traces weaken over time. Spacing forces partial forgetting, which triggers reconstruction and re-encoding, strengthening retrieval routes. Optimal gaps scale with the target retention interval: longer-term goals need longer lags. Classroom-applied distributed practice shows a moderate advantage over massed practice (d = 0.54). In a roadmap, treat each knowledge component as an item with a predicted recall probability. Schedule the next review when predicted recall drops into a "desirable difficulty" band (hard but likely retrievable), then expand intervals as stability increases. Pure spacing helps retention most reliably; transfer and conceptual integration often need additional mechanisms. Too-long gaps can push recall to zero, turning "review" into re-learning.

## How does retrieval practice (the testing effect) accelerate learning?
Retrieving is not just assessment. The act of recall changes memory by strengthening retrieval cues and improving future access, often outperforming additional study even when immediate performance looks worse. Meta-analytic estimates show practice testing vs restudying yields a medium benefit (g ≈ 0.51). Every roadmap step must end with a closed-loop retrieval check (free recall, short answer, problem completion) before any reread. Log correctness plus confidence, then route errors into immediate targeted feedback and a short re-test, followed by spacing. Retrieval without feedback can stabilize wrong answers. Benefits shrink when practice tests and final tests are mismatched in format.

## How does interleaving differ from blocked practice?
Mixing problem types forces discrimination ("what kind of problem is this?") and repeated strategy selection, creating more flexible retrieval. It also creates spacing between same-type items as a side effect. Overall interleaving effect is moderate (g = 0.42) but strongly moderated by material: stronger for visual category-learning tasks, small for math (g ≈ 0.34), and can reverse for word materials. After initial exposure, practice sessions should rotate between related subskills (A-B-C-A-B-C). Interleave "confusable" categories to train discrimination. Interleaving can hurt when tasks are too dissimilar or when learners have not yet built minimum schemas to recognize categories.

## What are desirable difficulties and how should difficulty be calibrated?
Conditions that increase difficulty during learning can improve later retention and transfer when they trigger deeper processing and successful retrieval. The key constraint is "manageable": difficulty must raise effort, not collapse performance into repeated failure. In the roadmap engine, treat "ease" signals as suspicious. Prioritize actions that reduce fluency but preserve success: delayed tests, varied contexts, mixed problem sets, and prediction before feedback. Use success-rate targeting (aim for roughly 70-85% success on retrieval) to keep difficulty desirable rather than destructive. Cranking difficulty without adequate prior knowledge creates noise, frustration, and errors that stick.

## How does cognitive load theory affect roadmap design?
Working memory has hard limits. When learning tasks demand more cognitive processing than working memory can handle, learning fails regardless of motivation or time invested. Novices need more support (worked examples, completion tasks, faded guidance) because they lack schema to chunk information. As expertise grows, that same support becomes redundant and can actually hurt (expertise reversal effect). Roadmaps must adapt scaffold levels to expertise: high support for novices, progressively removed as competence rises.

## When should worked examples be used versus problem-solving?
Worked examples reduce extraneous cognitive load by showing complete solutions. They are most effective for novices and when procedures are complex. As learners gain expertise, shift to completion problems (fill missing steps), then to full problem-solving. The worked-example effect reverses for advanced learners: too much guidance becomes redundant and slows progress. Implementation: use a "copy-then-create" progression. Start by reconstructing high-quality existing work, shift to completion problems, then to full original creation.

## How does dual coding improve learning?
Processing information through both verbal and visual channels creates more retrieval routes. Drawing-to-learn meta-analysis reports g = 0.69 for factual outcomes. For each roadmap node, require a "representation pair": a compact verbal summary plus a diagram, flowchart, or labeled sketch. Prefer constrained drawing tasks (complete, label, compare two diagrams) over "draw anything." Visuals can be decorative noise. If the diagram does not map onto the problem structure, it adds extraneous load.

## How does productive failure and generation before instruction work?
Learners attempt solutions or generate guesses using prior knowledge before receiving instruction. This activates features, surfaces misconceptions, and creates "slots" for later instruction. Across 53 studies, problem solving followed by instruction beats instruction followed by problem solving (g = 0.36; high-fidelity implementations stronger). For each new concept, start with a constrained attempt: predict the answer, sketch a solution, or explain a mechanism before seeing the canonical version. Then teach using contrastive feedback. Benefits weaken for younger learners and when unscaffolded floundering overloads working memory.

## What is metacognitive monitoring and why does it separate fast learners from slow ones?
Fast learning depends on allocating study to the right targets. Monitoring converts "felt fluency" into actionable estimates, and calibration tightens the mapping between confidence and actual performance. Learning strategy instruction improves monitoring accuracy (g ≈ 0.565). Self-assessment interventions show meaningful performance gains (g = 0.585). Force predictions after each retrieval attempt, collect confidence and predicted future recall, then reveal calibration dashboards. Use calibration to drive scheduling: prioritize high-importance items with low confidence but partial success. Self-reports without anchoring to objective performance are noisy.

## How do self-regulated learning cycles work?
SRL is the control system around cognition: goals select tasks, monitoring guides adjustments, reflection updates strategies and beliefs. SRL interventions show positive moderate effects on achievement (ES ≈ 0.69). Metacognitive prompts improve SRL activities (g = 0.50) and learning outcomes (g = 0.40). Make each roadmap day a micro-cycle: set a specific objective and success criterion, execute a retrieval-heavy session, then do a short post-mortem (what failed, why, what to change). SRL training is not plug-and-play for novices: without external structure (templates, prompts, defaults), learners cycle on poor metrics like time spent or comfort.

## Key Takeaways
- Retrieval practice and spaced repetition are non-negotiable defaults for any learning plan
- Difficulty should be calibrated to ~70-85% success rate on retrieval attempts
- Scaffold level must adapt to expertise (high for novices, faded for intermediates, removed for advanced)
- Metacognitive calibration (confidence vs performance tracking) is what separates fast learners from slow ones
- Every principle has boundary conditions where it fails or reverses; the roadmap must respect these
