# Angle Generation: Systematic Frameworks for Multiplying Ideas

## Overview
Twelve frameworks for turning one seed idea into multiple distinct angles. Split into formal frameworks (journalism, rhetoric, creative writing) and practitioner methods (creator workflows). Each provides named angle types that can be systematically applied to any topic.

## Formal Frameworks

### News Values Filter
Map a seed idea to newsworthiness dimensions: Power elite, Celebrity, Entertainment, Surprise, Bad news, Good news, Magnitude, Relevance, Conflict, Shareability.
**How to apply:** Pick 3 values with the most tension, write one angle per value as "Value → specific hook → who is affected → why now."
**Best for:** Any event, claim, or development that can be framed as timely or consequential.

### Newsroom Story Paths
Eight story forms from one assignment: Issue/trend, Explanatory, Profile/human interest, Voices/perspective, Descriptive, Narrative, Investigative, Visual.
**How to apply:** Write one working headline per story type. Discard weak ones. Each type uses a different reporting question (Profile = "who," Explanatory = "how it works," Investigative = "what's hidden").
**Best for:** Seeds that can become mini-series — one event, multiple publishable packages.

### Stasis Theory (Classical Rhetoric)
Four questions that locate "what's actually in dispute": Fact/Conjecture (did it happen?), Definition (what is it really?), Quality (is it good/bad?), Policy (what should we do?).
**How to apply:** State the idea as a claim, generate one angle per stasis question, pick the 3 most alive for your audience.
**Best for:** Seeds that trigger disagreement, myth-vs-reality, evaluative debates, policy choices. Perfect for contrarian-but-defensible writing.

### Six Thinking Hats
Parallel thinking: White (information/data), Red (feelings/intuition), Black (risks/caution), Yellow (benefits/value), Green (alternatives/creativity), Blue (process/control).
**How to apply:** Pick 3 maximally different hats, generate hat-appropriate output, turn each into a publishable angle.
**Best for:** Ideas where you need balanced breadth without randomness.

### Classical Rhetoric Appeals × Branches
Cross two dimensions: Appeals (Ethos/credibility, Logos/logic, Pathos/emotion) × Branches (Deliberative/future action, Judicial/past responsibility, Epideictic/present praise-blame).
**How to apply:** Choose one appeal + one branch, write as "Branch goal + Appeal proof." Yields systematically different angles even when thesis stays constant.
**Best for:** Persuasion-heavy content: opinion essays, keynote-style posts, debate threads.

### Content Strategy Post Types
Angle = content vehicle with distinct reader intent: How-to guide, Case study, Data study, Listicle, Checklist, Template, News/trend, Expanded definition.
**How to apply:** Treat each post type as an angle constraint. Choose 3 with different intents (teach vs prove vs enable).
**Best for:** Educational creators and brands who need ideation tied to search and repeatable production.

## Practitioner Methods

### Theme × Style Content Matrix (Justin Welsh)
Cross your recurring topics with named post styles: Listicle, Motivational, Observation, Actionable, X vs Y, Contrarian.
**How to apply:** Write seed as theme, generate one post per style. Same theme, different structural constraint.
**Best for:** Turning one idea into 3-6 platform-native angles quickly (LinkedIn/X).

### Value Trilogy: Education–Inspiration–Entertainment (Ali Abdaal)
Three value types with different structures: Education (steps/process), Inspiration (transformation arc), Entertainment (character + tension).
**How to apply:** Write three value promises for the same idea, change the lead + structure to match each type.
**Best for:** Multi-platform creators adapting across formats.

### POP Writing: Personal–Observational–Playful (David Perell)
Same claim, different evidence type: Personal (lived experience), Observational (pattern/insight), Playful (surprising metaphor/witty frame).
**How to apply:** Write one version dominated by each variable. Keep the claim constant, change the proof.
**Best for:** Creators who sound "same-y" and need systematic differentiation.

### Spiky Point of View (Wes Kao)
Sharpen a debatable, evidence-rooted, conviction-backed thesis. Then decompose into: Thesis post, Evidence post, "Common objection" rebuttal post.
**How to apply:** Write the middle-of-the-road take → sharpen into debatable thesis → attach evidence → pre-write strongest rebuttal → each element becomes its own angle.
**Best for:** Finding non-obvious angles competitors miss. Forces stances that are bold but defensible.

### Hero–Hub–Help (Google/YouTube)
Three audience intents: Help (solve my problem — always-on search answers), Hub (keep me coming back — recurring series), Hero (make me pay attention — tent-pole event content).
**How to apply:** Same idea, different audience intent. Help = utility, Hub = series, Hero = emotion/event.
**Best for:** Cross-platform adaptation where re-angling matters more than reformatting.

## Implementation Note
The strongest angle generation combines at least two frameworks from different disciplines. Example: Stasis Theory (what's in dispute) + Story Paths (what story form) prevents same-angle repetition while staying systematic. Or: Six Hats (which perspective) + Post Types (which format). Running 3-4 frameworks in parallel, then selecting the most structurally distinct angles, produces the highest-quality output.
