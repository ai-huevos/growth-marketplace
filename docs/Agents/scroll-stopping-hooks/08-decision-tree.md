# Decision Tree: Picking the Right Framework for the Job

## Overview
A routing guide that connects goals, platforms, and audience types to the right combination of frameworks and techniques across all other files.

## By Target Action

### Goal: Maximize Shares
Shares involve reputational risk. The sharer must look good for passing it on.
- **Primary driver:** Identity signaling + high-arousal emotion (01)
- **Angle approach:** Contrarian or provocation lens (prompt), Spiky Point of View (04)
- **Hook framework:** Strong declarative or controversial opinion opener (02)
- **Audience psychology:** Social currency, identity tribe fit (05)
- **Platform priority:** X (fast reshare mechanic), LinkedIn (professional signal value)

### Goal: Maximize Saves
Saves are private future-self utility. The content must be worth returning to.
- **Primary driver:** Specificity bias + practical value (01, 05)
- **Angle approach:** How-to/tactical lens (prompt), Content Strategy Post Types (04)
- **Hook framework:** Deliverable + objection smasher, curation thread (02)
- **Audience psychology:** Practical value, reusable assets (05)
- **Platform priority:** Instagram (save rate is a strong algorithm signal), LinkedIn (professional reference)

### Goal: Maximize Comments
Comments require cognitive effort and public risk. The content must provoke a response.
- **Primary driver:** Cognitive dissonance + moral-emotional language (01, 05)
- **Angle approach:** Myth-busting or stakes-raising lens (prompt), Stasis Theory quality/policy questions (04)
- **Hook framework:** Negative checklist, thought-provoking question opener (02)
- **Audience psychology:** Moral-emotional framing, expertise calibration (05)
- **Platform priority:** LinkedIn (comments are an algorithm signal), TikTok (comments as creative surface)

### Goal: Maximize Watch Time (Video)
Watch time requires sustained attention. The hook must promise and deliver in micro-payoffs.
- **Primary driver:** Open loop + loss aversion (01)
- **Angle approach:** Story or personal experience lens (prompt)
- **Hook framework:** StoryTweet 3-act, bomb-under-the-table (02, 07)
- **Audience psychology:** High-arousal emotion sustains attention (05)
- **Platform priority:** TikTok (play duration is core metric), YouTube Shorts (swipe-away rate)

## By Platform

### X
- **Best mechanisms:** Curiosity gap, specificity bias, pattern interrupt (01)
- **Best frameworks:** Deliverable + objection smasher, eye-catching numbers, strong declarative (02)
- **Best angles:** Data/evidence, contrarian, myth-busting (prompt)
- **Avoid:** Long preambles, compound sentences, context-setting before the point (03)

### LinkedIn
- **Best mechanisms:** Identity signaling, loss aversion, specificity bias (01)
- **Best frameworks:** Relatable enemy > hero > gasoline, trailer stack, negative checklist (02)
- **Best angles:** Contrarian (professional), stakes-raising, how-to (prompt)
- **Avoid:** Entertainment-first hooks, casual tone, engagement bait questions (03)

### Instagram
- **Best mechanisms:** Identity signaling, pattern interrupt, cognitive dissonance (01)
- **Best frameworks:** Juxtaposition before/after, identity hooks, vulnerable opener (02)
- **Best angles:** Personal experience, story, analogy (prompt)
- **Avoid:** Text-only hooks, familiarity assumptions, reposts without transformation (03)

### TikTok
- **Best mechanisms:** Pattern interrupt, open loop, loss aversion (01)
- **Best frameworks:** Found-artifact cold open, status-transaction tilt, bomb-under-the-table (02, 07)
- **Best angles:** Story, data/evidence, provocation (prompt)
- **Avoid:** Retention-begging, polished/corporate tone, follower-context hooks (03)

### YouTube Shorts
- **Best mechanisms:** Pattern interrupt, curiosity gap (01)
- **Best frameworks:** Visual reveal, found-artifact (02, 07)
- **Best angles:** Data/evidence, how-to, story (prompt)
- **Avoid:** Slow builds, TikTok watermarks, caption-dependent hooks (03)

### Threads
- **Best mechanisms:** Identity signaling, cognitive dissonance (01)
- **Best frameworks:** Controversial opinion opener, observational opener (02)
- **Best angles:** Analogy, wildcard, personal experience (prompt)
- **Avoid:** LinkedIn-style professional hooks, hard-sell, broadcast tone (03)

### Bluesky
- **Best mechanisms:** Specificity bias, curiosity gap (01)
- **Best frameworks:** Weird/unique insight opener, strong declarative (02)
- **Best angles:** Data/evidence, analogy, myth-busting (prompt)
- **Avoid:** Growth-hack tactics, guru templates, engagement bait (03)

## By Audience Expertise Level

### Novice Audience
- **Optimize for:** Saves (practical utility)
- **Mechanisms:** Specificity bias, curiosity gap (01)
- **Angle approach:** How-to, deliverable + objection smasher (prompt, 02)
- **Tone:** Concrete steps, fast wins, definitions included
- **Avoid:** Jargon, assumed knowledge, boundary-condition discussions

### Expert Audience
- **Optimize for:** Shares (peer signal value) and comments (peer debate)
- **Mechanisms:** Cognitive dissonance, pattern interrupt (01)
- **Angle approach:** Contrarian, myth-busting, TRIZ contradiction (prompt, 07)
- **Tone:** Boundary conditions, failure modes, non-obvious synthesis
- **Avoid:** Over-simplification, "101" framing, explaining things they already know

## When Standard Approaches Feel Flat

If the first round of angles from standard lenses (prompt) + practitioner frameworks (02) + formal angle frameworks (04) all feel similar, escalate to non-obvious techniques (07):

1. Try Kuleshov Pair if the insight is better "discovered" than stated
2. Try Bomb-Under-the-Table if you have a genuinely surprising finding
3. Try Status-Transaction Tilt if there's a reversed power dynamic
4. Try Found-Artifact if you have real data or a real moment
5. Try TRIZ Contradiction if the seed contains a hidden tradeoff
6. Try OuLiPo Constraint if you're stuck in a structural pattern
