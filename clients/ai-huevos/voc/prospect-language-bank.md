## Instrucciones de Uso

### Para contenido

1. Buscar frases relevantes por cluster temático
2. Usar verbatim como apertura de emails, landing sections, o posts
3. Formato: "Un COO nos escribió: '[verbatim]'" — siempre entre comillas
4. NUNCA editar las frases — usar exactamente como el prospecto las escribió

### Para ventas

1. Antes de una call, buscar el Q10 verbatim del lead en el CRM
2. Abrir con: "Mencionaste que tu mayor problema es [verbatim]..."
3. Mapear la frase a la dimensión PULSO más relevante

### Para actualización

1. Exportar Q10 responses del quiz (Tally → CSV)
2. Copiar frases verbatim a la sección correspondiente
3. Clusterizar cuando hay 5+ frases similares
4. Marcar fecha de cada batch
