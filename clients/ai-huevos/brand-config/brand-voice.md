## Reglas de Voz

| Regla | Hacer | No hacer |
|-------|-------|----------|
| **Lead with impact** | "$15M en ahorros encontrados en 3 semanas" | "Después de un análisis exhaustivo, se identificaron oportunidades..." |
| **Short sentences** | "Los sistemas estaban desconectados. La información no fluía. Nadie sabía qué pasaba." | "La falta de integración entre sistemas generaba una carencia de visibilidad operativa..." |
| **Name the problem** | "Tu equipo opera con WhatsApp y Excel. Eso no escala." | "Existen áreas de mejora en los procesos de comunicación..." |
| **Numbers up front** | "44 entrevistas. 5 departamentos. 3 cuellos de botella." | "Se realizó un proceso de entrevistas que abarcó múltiples áreas..." |
| **Active voice** | "Conectamos tus sistemas." | "Los sistemas fueron conectados por nuestro equipo." |
| **Close with action** | "Agenda una demo. Encontremos tus $15M." | "Si desea más información, no dude en contactarnos." |

## Vocabulario de Marca

### Usar siempre

| Término AI Huevos | En vez de |
|-------------------|-----------|
| Conectar | Integrar |
| Encontrar | Identificar |
| Construir rieles | Implementar soluciones |
| Organizaciones | Empresas (genérico) |
| Arqueología organizacional | Análisis / discovery |
| Director AI | Chatbot, asistente |
| Nos quedamos | Soporte post-implementación |

### Nunca usar

- "Solución end-to-end" (corporate speak)
- "Leverage" / "Synergy" (buzzwords)
- "Disruptivo" (overused)
- "Robusto" (vacío)
- "De clase mundial" (cliché)
- "Cutting-edge" / "State-of-the-art" (genérico)
- "Seamless" (nadie cree eso)

## Estructura Narrativa (Bold Pattern)

Todo contenido sigue este arco:

```
1. GOLPE   → Dato impactante o problema crudo
2. DOLOR   → Por qué importa (consecuencia real para el negocio)
3. PUENTE  → Cómo AI Huevos resuelve esto
4. PRUEBA  → Caso real / métrica / testimonio
5. ACCIÓN  → Qué hacer ahora (CTA concreto)
```

### Ejemplo aplicado

```
GOLPE:  "Tu CRM tiene 15,000 contactos. Solo 200 están actualizados."
DOLOR:  "Cada semana tu equipo de ventas pierde 8 horas buscando info que ya existe."
PUENTE: "Conectamos tu CRM con WhatsApp y email. La información fluye sola."
PRUEBA: "En Finkargo, redujimos el tiempo de búsqueda de 45 min a 3 min por caso."
ACCIÓN: "Agenda 30 minutos. Te mostramos dónde está tu $15M escondido."
```

## Mensajes Clave

### Taglines (uso en todo contenido)
- "Pa' emprender se necesitan huevos"
- "AI tastes better with eggs"
- "Nos gustan los huevos que vienen con AI por dentro"

### Value props (orden de prioridad)
1. **Arqueología organizacional** — Mapeamos la realidad, no el organigrama
2. **Construimos rieles** — No soluciones aisladas, conexiones entre sistemas
3. **Nos quedamos** — No somos consultores que dejan PowerPoints
4. **Track record** — 3 años, $650M en transacciones, Finkargo como prueba

### Promesa
- Encontrar $15M+ en oportunidades de ahorro
- Automatizar procesos en 2-3 semanas (no meses)
- Conectar todos tus sistemas (WhatsApp, Excel, SAP, Oracle)
- Visibilidad real de qué está pasando en tu organización
